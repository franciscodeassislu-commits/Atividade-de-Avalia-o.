# 📚 Atividade de Avaliação — Web Development



Página desenvolvida como atividade prática para treinar os conceitos fundamentais de HTML e CSS.

---

## 📌 O que foi feito nesta etapa

* **Estilização do Header:** Adicionámos cor de fundo e alinhamento ao cabeçalho.
* **Ajuste das Imagens:** Centralizámos as imagens dos cards para ficarem organizadas.
* **Layout com Grid:** Utilizámos CSS Grid para organizar os cards lado a lado.
* **Controlo de Versões:** Criação do repositório no Git e sincronização com o GitHub.

> 🚀 **Próximos passos:** Na próxima etapa faremos a finalização do projeto e os últimos ajustes finos de layout!

---

## 🛠️ Tecnologias

* HTML5
* CSS3 (Grid e Flexbox)
* Git & GitHub

---
## 📄 Novas Páginas e Desafios

Nesta etapa, adicionei o arquivo `dificil.html` para documentar as dificuldades enfrentadas durante o desenvolvimento (como problemas de responsividade, sobreposição de cards e alinhamento de textos). O objetivo principal foi consolidar o fluxo de versionamento com Git e GitHub, priorizando a prática de commit e push em vez de um layout perfeito.
