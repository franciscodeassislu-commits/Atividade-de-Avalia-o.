# 📚 Atividade de Avaliação — Web Development



Página desenvolvida como atividade prática para treinar os conceitos fundamentais de HTML e CSS.

## 📌 O que foi feito nesta etapa

* **Estilização do Header:** Adicionámos cor de fundo e alinhamento ao cabeçalho.
* **Ajuste das Imagens:** Centralizámos as imagens dos cards para ficarem organizadas.
* **Layout com Grid:** Utilizámos CSS Grid para organizar os cards lado a lado.
* **Controlo de Versões:** Criação do repositório no Git e sincronização com o GitHub.
